# Animated fish samples

Twenty GIFs made with `FishDraw_Fast.js`. Each fish changes shape over 25 steps, pauses, then returns to its starting shape. The drawing seed, switches and categorical styles stay fixed within each animation. A shared camera keeps every frame in view.

The collection covers four scale styles × five body patterns. Each pair has its own seed and endpoint parameters. These are invented fish, not illustrations of named species.

[See the full gallery](../README.md#animated-samples) · [Try the interactive studio](https://franky-fishdraw-studio-v2.frankmarsman.chatgpt.site/)

## Recreate the GIFs

With Node.js, FFmpeg on your PATH and the optional SVG renderer installed, run from the repository root:

```sh
npm install --no-save @resvg/resvg-js@2.6.2
node demo/render-gallery.cjs
```

The script generates `morph-01.gif` through `morph-20.gif` and `manifest.json`. It overwrites those generated files. No browser or network is used while rendering.

The manifest records the generator hash, drawing seeds, exact endpoint parameters, shared bounds and geometry hashes for every frame. The GIFs are 480 × 300 pixels, play at 20 fps and loop in both directions with endpoint pauses. Preparation time is omitted, so playback is not a performance benchmark.

All frames are generated by the library; none are cross-fades between still images. The same numeric interpolation and integer rounding as Frank Fish are used, while all categories stay fixed to avoid abrupt style changes.

Based on [Fishdraw by Lingdong Huang](https://github.com/LingDong-/fishdraw), under the repository's [MIT license](../LICENSE).
